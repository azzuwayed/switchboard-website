What it does

Service dashboard

Running, degraded, stopped, and unknown states across every service kind in a single view.

Risk-aware actions

Start, stop, restart, update — every command is allowlisted, approved, and runs without a shell.

Templates

Postgres, MySQL, MongoDB, Redis, Docker Compose, Ollama, nginx, generic HTTP + command — all reviewed and ready.

Port inspector

See every listening port, link processes to services, and resolve conflicts without lsof.

Health checks

Homebrew, Docker, HTTP, and command-backed health probes with live polling.

Local-only

No telemetry, no analytics, no background server. Config and logs live in your Application Support folder.

Trust model

Switchboard is designed to be useful without becoming a shell-in-a-webview.

  • Runs entirely on your Mac.
  • No cloud account.
  • No background HTTP server.
  • No arbitrary shell from the UI.
  • The webview sends only serviceId, action, and explicit confirmation state.
  • Rust maps actions to exact allowlisted cmd + args definitions.
  • Commands run through tokio::process::Command, never sh -c.
  • Imported commands are previewed command-by-command before they can run.
  • New or changed imported commands stay unapproved until reviewed.
  • Command output is bounded; secret redaction defaults to on.
